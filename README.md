# school-waste-ai

# ขยะรีไซเคิลสะอาดขึ้นด้วยโปสเตอร์และกล้อง AI

โครงงาน AI ระดับมัธยมศึกษา · ตัวอย่างประกอบหลักสูตร AI Project-Based Learning (Design Thinking)

## ที่มาและปัญหา
โรงเรียนมี 3 ถัง (ทั่วไป · รีไซเคิล · เศษอาหาร) และไม่มีจุดล้างภาชนะ ผู้ทิ้งขยะจึงทิ้งภาชนะที่ยังมีน้ำหรือเศษอาหาร
- ชิ้นในถังรีไซเคิล **28%** ยังมีของเหลวหรือเศษอาหาร (สุ่มตรวจ 10 จุด)
- ผู้ตอบแบบสอบถาม **40%** (กลุ่ม B) สับสนเฉพาะขยะที่มีของเหลวหรือเศษอาหาร

## ข้อมูล
| ไฟล์ | รายละเอียด |
|---|---|
| `data/survey_kaya_clean.csv` | แบบสอบถามขยะ 5 รายการ 305 คน ก่อนติดโปสเตอร์ (ลบอีเมลและแถวซ้ำแล้ว) |
| `data/survey_kaya_post.csv` | แบบสอบถามเดิม 305 คน หลังติดโปสเตอร์ 2 สัปดาห์ (ลบอีเมลแล้ว) |
| ภาพขยะสำหรับฝึกแบบจำลอง | RealWaste 3 ถัง ถังละ 180 ภาพ (ไม่ได้เก็บไว้ใน Repository — ดูการอ้างอิงด้านล่าง) |

## วิธีการและผลลัพธ์
1. จัดกลุ่มผู้ตอบด้วย K-means (k = 3) → พบกลุ่ม B ที่สับสนเรื่องของเหลวและเศษอาหาร
2. **ต้นแบบที่ 1** โปสเตอร์ 3 ขั้น ติด 5 จุด เทียบกับ 5 จุดที่ไม่ติด
   - ถังรีไซเคิลปนเปื้อนลดจาก 28% เหลือ 15% (จุดไม่ติดโปสเตอร์ 27% → 25%)
   - กลุ่ม B ลดจาก 40% เหลือ 27%
3. **ต้นแบบที่ 2** กล้อง AI ณ จุดทิ้งขยะ — แบบจำลอง Teachable Machine จำแนก 3 ถัง ความแม่นยำ 87% กับภาพทดสอบ

## ข้อจำกัด
- ทดสอบโปสเตอร์เพียง 2 สัปดาห์ ในโรงเรียนเดียว
- แบบจำลองฝึกด้วยภาพจากต่างประเทศ ยังไม่ได้ทดสอบกับขยะจริงในโรงเรียน และยังสับสนระหว่างถังทั่วไปกับถังรีไซเคิล
- แบบจำลองบอกประเภทถังได้ แต่ไม่รู้ว่าภาชนะมีเศษอาหารหรือไม่ จึงแสดงข้อความ "เทน้ำและเศษอาหารออกก่อน" ทุกครั้งที่เป็นรีไซเคิล
